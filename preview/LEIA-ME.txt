COMO REGERAR

  npm i playwright ffmpeg-static
  npx playwright install chromium
  # (no Linux pode faltar libnspr4, libnss3 e libasound2 para o Chromium subir)

  # MOBILE — é o padrão do script
  node capturar-gif.mjs ./frames-mobile

  ffmpeg -framerate 30 -i frames-mobile/f%04d.png \
    -vf "scale=1080:-2:flags=lanczos,format=yuv420p" \
    -c:v libx264 -crf 18 -preset slow -movflags +faststart -y site-scroll-mobile.mp4

  ffmpeg -framerate 30 -i frames-mobile/f%04d.png -vf "fps=20,scale=420:-1:flags=lanczos" \
    -c:v libwebp_anim -lossless 0 -q:v 45 -loop 0 -y site-scroll-mobile.webp

  # DESKTOP — mesmo script, medidas por variável de ambiente
  VP_W=1280 VP_H=800 VP_DPR=2 SEG_SCROLL=35 node capturar-gif.mjs ./frames-desktop

  ffmpeg -framerate 30 -i frames-desktop/f%04d.png \
    -vf "scale=1920:-2:flags=lanczos,format=yuv420p" \
    -c:v libx264 -crf 18 -preset slow -movflags +faststart -y site-scroll-desktop.mp4

  ffmpeg -framerate 30 -i frames-desktop/f%04d.png -vf "fps=20,scale=800:-1:flags=lanczos" \
    -c:v libwebp_anim -lossless 0 -q:v 45 -loop 0 -y site-scroll-desktop.webp

VARIÁVEIS ACEITAS PELO capturar-gif.mjs
  SITE_URL ..... endereço do site (padrão: ../index.html ao lado do script)
  VP_W / VP_H .. tamanho da janela (padrão 390x844)
  VP_DPR ....... fator de escala da captura (padrão 3)
  VP_FPS ....... quadros por segundo (padrão 30)
  SEG_SCROLL ... segundos de rolagem (padrão 50)

Cada captura ocupa ~650 MB temporários e leva ~5,5 min.

Para regerar os placeholders azuis das fotos: node gerar-placeholders.mjs
